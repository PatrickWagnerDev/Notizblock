# Notizblock

Notizblock is a simple online notepad created as an exercise to practice LocalStorage and implementing add, display, edit, and delete functionality with JavaScript.

The project is intended for educational purposes only and is not planned for production or deployment.

## Features

* Add notes – Create and save new notes
* View notes – Display all saved notes
* Edit notes – Update existing notes
* Delete notes – Remove notes that are no longer needed
* Local storage – Store notes in the browser using LocalStorage

## Technologies

* HTML
* CSS
* JavaScript
